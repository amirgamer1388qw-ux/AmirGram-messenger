# 👋 Hi, I'm Amir

I'm Amir, the creator and developer of AmirGram.

AmirGram is a private real-time messaging platform designed for small teams, friends, and private communities. The goal of this project is to let you create and host your own messenger instead of depending on third-party messaging platforms.

## 🚀 About AmirGram

With AmirGram, you can:

- 💬 Send messages in real time
- 👤 Create user accounts
- 📁 Share files
- ✅ Track message status
- 💾 Store data locally
- 🌐 Connect with friends from anywhere in the world
- 🖥️ Host your own messenger

The project is built with:

- Node.js
- Express
- Socket.IO
- Multer

## ▶️ How to Run

1. Install Node.js on your computer.
2. Download or clone this repository.
3. Open CMD or Terminal inside the project folder.
4. Run:

   npm install

5. Start AmirGram:

   npm start

6. Open your browser and go to:

   http://localhost:3000

That's it! 🎉 Your AmirGram messenger is now running.

For VPS, Android/Termux, domain, HTTPS, and other hosting methods, see `SETUP_AND_HOSTING.txt`.
